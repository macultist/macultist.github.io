# 반도체 소자 파라미터 추출기 — 만든 과정 (2026-09-12)

## 1. 목표
- 전자전기 전공 학부생·연구실이 MOSFET·다이오드 측정 파일을 올리면 파라미터를 여러 기법으로 한꺼번에 뽑아 비교하는 도구.
- 100% 브라우저 계산(파일이 서버로 가지 않음), 빌드 도구·외부 라이브러리 없음.

## 2. 만든 것
- 파서: CSV/TSV/공백, 소수점 쉼표, 주석 줄, Keithley 식 헤더 자동 매핑, B1500 EasyEXPERT(DataName/DataValue) 형식.
- 전달특성: Vth 4기법(ELR·CC·SD·gm/Id), SS, Ion/Ioff, gm,max, 이동도, 히스테리시스, Vd 별 비교표.
- 출력특성: gd·ro·λ·VA·Ron. 다이오드: n·Is·Rs(2방법)·턴온 3정의·정류비.
- SVG 플로터, 마크다운/CSV 리포트, 기법 원리·한계 설명, 합성 예제.
- 테스트: 합성 곡선(잡음 0/1/3%) 67개 항목. ELR ±20 mV, SS ±5 mV/dec 등.

## 3. 알고리즘 조정 (테스트로 드러난 것)
- ELR 단일 점 접선은 잡음 3% 에서 ±100 mV 넘게 흔들려 gm ≥ 0.8·gm,max 구간 직선 회귀로 교체.
- gm/Id 는 d(ln Id)/dVg 로 직접 계산. SD 는 창을 두 배로, 포화영역은 √Id 기준.
- 이동도는 gm 최댓값 대신 ELR 회귀 기울기 사용.

## 4. 저장소와 배포 (petfee / daytrade 와 같은 구조)
- 처음: `macultist/macultist.github.io` 브랜치의 `devparam/` 폴더에 소스째 두었음.
- 분리:
  - `macultist/devparam-src` (비공개): 소스, 테스트, 빌드 스크립트, 워크플로, 기록.
  - `macultist/devparam` (공개): 완성 화면(뭉갠 JS, 압축 CSS, 무단 복제 금지 표시)만. Pages 는 main 루트.
  - 연결: devparam-src 의 자동화가 배포 열쇠(SSH 배포키)로 devparam 에 강제 푸시. 공개키는 devparam 배포키, 비밀키는 devparam-src 시크릿 PAGES_DEPLOY_KEY.
  - 자동 실행: 매일 04:10 KST 점검(내용이 바뀐 경우에만 갱신) + main 푸시 시 즉시. 테스트가 실패하면 배포하지 않음.
  - 공개 저장소의 코드 이력: 브랜치를 [대문 등록 커밋] 만 남기고 정리 (`tools/setup-split.sh` 4단계).
- 주소: https://macultist.github.io/devparam/

## 5. 한계와 확인 필요
- 실제 Keithley/B1500 파일로 헤더 인식 검증 필요.
- ELR 회귀 구간 80% 기준은 이동도 저하가 큰 소자에서 Vth 를 조금 낮게 편향시킬 수 있음(화면에서 조절 가능).
